## Security Checklist (auto-verified during scaffold)

Before emitting the skeleton, the `mcp-builder` subagent validates the following against `mcp-server-safety`:

| Control | Rule | Verified |
|---|---|---|
| Tool allowlist is closed (no wildcard tool registration) | `mcp-server-safety` | ☐ |
| Each tool declares minimum required permissions only (`agentic-tool-scoping`) | `agentic-tool-scoping` | ☐ |
| Caller token is delegated via OBO flow, not static credential reuse | `agentic-obo-auth` | ☐ |
| Human-approval gate is wired for destructive/write tools | `agentic-human-approval` | ☐ |
| Every tool invocation writes an audit-log line to `.securecode/audit.log` | `ai-audit-logging` | ☐ |
| No tool has `filesystem: write` on paths outside a declared sandbox directory | `mcp-server-safety` | ☐ |
| Server binds only to loopback or VPN-restricted interface in dev | `mcp-server-safety` | ☐ |
| Error responses do NOT include stack traces or internal paths | `error-handling` | ☐ |
